# 30. REGLA PARA AGENTES DE IA

Antes de implementar personalizaciones:

1. Leer `BASE_MASTER.md`.
2. Leer este `CLIENT_TEMPLATE.md`.
3. Identificar diferencias entre CORE y requerimientos específicos.
4. No modificar el CORE cuando una solución pueda implementarse mediante configuración.
5. Crear módulos adicionales de forma desacoplada cuando sea posible.
6. No eliminar funcionalidades existentes sin autorización.
7. Revisar dependencias antes de realizar cambios.
8. Ejecutar pruebas sobre los módulos afectados.
9. Registrar nuevas reglas empresariales en `BUSINESS_RULES.md`.
10. Actualizar `CURRENT_STATUS.md` después de cambios relevantes.
