# 08-CURRENT_STATUS.md

# Estado Actual del CORE

Este documento registra el estado global del CORE del Sistema de Gestión
Inmobiliaria / Terrenos.

NO representa el estado de implementación de un cliente específico.

El estado particular de cada cliente debe mantenerse en:

`/clients/{CLIENTE}/IMPLEMENTATION_STATUS.md`

---

# 1. Objetivo

Este archivo responde principalmente:

1. ¿Qué está definido en el CORE?
2. ¿Qué está implementado realmente?
3. ¿Qué funcionalidades siguen pendientes?
4. ¿Qué decisiones globales están vigentes?
5. ¿Cuál es la siguiente prioridad del CORE?

No utilizar este archivo para registrar personalizaciones comerciales
de clientes.
